ForgeWorks is a from-scratch, GitHub-compatible git forge built for the make.fun github-core-clone-01
bounty. It serves git smart HTTP (upload-pack v2 and receive-pack v0), a subset of the REST v3 API,
GraphQL introspection and operations, and MCP 2026-07-28 tools, backed by an in-process store. It
runs on Node 22 with no external services and no git binary.

## Run it

```sh
node main.ts
```
